# 12. Anti-slop: o que denuncia página feita sem pensar

Cada item abaixo é sintoma de que ninguém pensou no nicho, no público ou na história. Troque pelo que está ao lado.

## Estrutura

| Sintoma | No lugar |
|---|---|
| Três cards idênticos lado a lado com ícone, título e duas linhas | a estrutura dominante certa do catálogo (`03-composicao.md`) derivada da metáfora |
| Passo a passo "1, 2, 3" em fila de ícones | escada diagonal, linha do tempo vertical ou pilha sobreposta |
| Tudo encostado à esquerda, um bloco embaixo do outro | eixo escolhido por capítulo, grade de 12 com arranjos 7/5, 8/4 |
| Seção de "benefícios" e outra de "vantagens" | uma seção só, com a função escrita |
| Hero com 3 parágrafos e 2 botões iguais | uma frase, uma linha de apoio, um CTA (o secundário em contorno) |
| Faixa com 4 números iguais ("+500 clientes", "+10 anos"…) | o número mais forte, gigante, com contexto; os outros pequenos ou fora |
| Logo de "empresas que confiam" inventadas | prova real ou demonstração |
| Rodapé com 40 links em 5 colunas | rodapé como último capítulo: chamada → prático → legal, com a forma da metáfora (`14-cabecalho-rodape.md`) |
| Linha cinza de 1px entre seções, ou troca seca de fundo | costura: elemento que atravessa, forma da metáfora, sobreposição, pergunta-ponte (`13-costuras.md`) |
| Todas as seções com o mesmo padding | ritmo: 1× quando continua, 2× quando muda de assunto, 3× na virada |
| Cabeçalho fixo de 90px com menu hambúrguer e o CTA escondido dentro | cabeçalho de 56–64px, CTA fora do menu, comportamento escolhido (some, encolhe, vira barra de ação) |
| Foto de banco genérica só para "ter imagem" | efeito desenhado com código ou nenhuma imagem (`15-efeitos.md`) |
| Card dentro de card | um nível só |
| Carrossel automático | grade ou pilha estática; carrossel só se o visitante controla |

## Visual

| Sintoma | No lugar |
|---|---|
| Gradiente roxo-azul genérico, glow neon, blob desfocado de fundo | a paleta do nicho e da metáfora |
| Glassmorphism em tudo | material da metáfora; vidro só se a metáfora pede (como o portal do Olimpo) |
| Emoji como ícone em botão, título ou lista | ícone de traço uniforme (uma biblioteca só) ou nenhum |
| Sombra pesada e borda colorida no mesmo card | sombra macia **ou** borda fina, não os dois |
| Foto de banco com gente sorrindo para a câmera | foto real, tela real do produto ou prompt específico |
| Texto cinza-claro sobre branco | contraste do público (4,5:1 ou 7:1) |
| 4 fontes diferentes | no máximo 2 famílias |
| Tamanhos inventados (13, 17, 22, 35px soltos) | degraus do `tokens.css` |

## Copy

| Sintoma | No lugar |
|---|---|
| "Eleve seu negócio a outro nível" | o resultado concreto, com número |
| "Solução completa / inovadora / revolucionária" | o que faz, em verbo |
| "Bem-vindo ao nosso site" | a frase do hero |
| "Saiba mais", "Clique aqui", "Enviar" | o que acontece ao clicar |
| "Qualidade e excelência", "Compromisso com você" | a prova que justificaria a frase |
| "Nós somos uma empresa que…" | o que o cliente ganha |
| Depoimento genérico sem nome nem contexto | avaliação real com nome e fonte, ou nada |
| Urgência falsa (contador que reinicia, "últimas vagas" eternas) | prazo real ou nenhum |

## Movimento

| Sintoma | No lugar |
|---|---|
| Tudo entrando com fade-up ao rolar | só onde orienta; o hero aparece no primeiro quadro |
| Parallax em várias camadas | uma imagem estática bem enquadrada |
| Elemento pulsando sem parar | confirmação única quando faz sentido |
| Cursor customizado | o cursor do sistema |
