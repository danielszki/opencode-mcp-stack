# 11. Combinando com outras skills

O chicote decide **o quê** e **por quê**: história, público, composição, medidas e nota. Outras skills trazem técnica para executar uma parte melhor. Elas nunca derrubam uma regra do chicote. Se uma skill mandar algo que reprova num portão (ex.: animação que roda para sempre, texto de 14px para idoso), vale o chicote.

## Como combinar

1. A pessoa cita a skill (ex.: "usa a de animação") ou você vê uma instalada que resolve uma parte.
2. Termine os passos 1 a 5 do chicote primeiro (ficha, roteiro, metáfora, medidas, composição). A outra skill entra no passo 6 ou 7.
3. Passe para ela o contexto que importa: a ficha, os tokens e a composição.
4. O resultado dela passa pela chicotada como qualquer outra coisa.

## Encaixes comuns

| Precisa de | Tipo de skill que ajuda | Entra no passo |
|---|---|---|
| Direção de arte, paleta, combinação de fontes | gosto visual / anti-slop / design system | 3 e 4 (sem trocar os números do `medidas.mjs`) |
| Animação, coreografia, gestos | animação | 6 |
| Tipografia fina (kerning, aspas, quebras) | tipografia | 7 |
| Oferta, preço, garantia | oferta / preço / marketing | 2 |
| Teste com público simulado | painel de consumidores | 2 (validar a frase do hero) |
| Auditoria extra de acessibilidade e responsivo | auditoria de UI | 8, junto com a chicotada |
| Testar com dados extremos (nome enorme, lista vazia) | quebrar UI | 8 |

## O que não fazer

- Não rodar três skills de "gosto" ao mesmo tempo: elas brigam e o resultado vira média sem identidade. Uma direção, uma metáfora.
- Não deixar outra skill reescrever a frase do hero sem passar de novo pelos 5 testes.
- Não aceitar número de outra skill (tamanho de fonte, contraste, alvo) abaixo do mínimo do público.
